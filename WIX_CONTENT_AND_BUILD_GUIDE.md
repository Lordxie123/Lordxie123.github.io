## Important portrait note
Your uploaded original portrait is embedded directly in `index.html` as a base64 data URI. It is displayed as a fixed image; the website has no visitor-facing image replacement control.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. No server, installation, or internet connection is required.

## Wix guide
Wix does not generally let you upload a complete standalone HTML website as a native Wix theme. To reproduce the design:
1. Create a blank Wix site and set the global colors to dark navy, mint, and soft white.
2. Add a sticky header with anchor links for About, Education, Qualification, Skills, Projects, Languages, and Contact.
3. Build the hero section with the heading, short profile, two CTA buttons, and the portrait.
4. Recreate the content sections using Wix containers, repeaters, and text elements.
5. Use Wix interactions for reveal animations, project popups, theme switching, and back-to-top behavior where supported.
6. Upload the original portrait to Wix Media and place it in a locked image element. Do not enable visitor upload/change controls.
7. Set the Contact button to `mailto:calderonjoshua240@gmail.com`.
